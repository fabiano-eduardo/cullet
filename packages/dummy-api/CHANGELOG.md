# @cullet/dummy-api

## 1.0.3

### Patch Changes

- 99300f1: fix(cli): bundle each kit's metadata into the CLI package so `cullet info`/`list` keep showing the kit's context, compatibility, peer deps and deprecation when the CLI runs installed from npm.

    Previously these were read from `packages/<name>/meta.json` and `KIT_CONTEXT.md`, which the published tarball does not ship, so an installed CLI silently degraded (e.g. `info` claimed a kit had no `KIT_CONTEXT.md`). Each kit's metadata is now snapshotted into `registry/kits/` (generated by `scripts/sync-kit-registry.mjs`, verified in CI) and read as a fallback when the monorepo source is absent.

    Also reposition `dummy-api` as an intentional minimal example kit instead of a "dummy" fixture in the published catalog.
